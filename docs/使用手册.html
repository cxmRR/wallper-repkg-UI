壁纸解包 · 使用手册

Wallpaper Engine 素材提取工具 · 版本 1.0.0

Windows 10 / 11 无需安装 .NET 内置解析引擎 支持图片 / 视频 / 网页壁纸

1这个工具能做什么

把 Wallpaper Engine 的壁纸素材解出来，挑你喜欢的部分保存到自己的文件夹。全程本地处理，不联网、不上传。

选择壁纸→ 自动识别类型→ 开始解包→ 预览挑选→ 保存到本地
核心原则：解包只是把素材准备好供你预览，不会自动往保存目录写文件。只有你点击「保存」或「保存视频」时，才会真正保存。

2支持的壁纸类型

类型识别依据解包结果
Scene 场景 目录或文件中含 scene.pkg 解出其中所有贴图，可在右侧逐张预览、挑选保存
纹理 单独的 .tex 文件 解出一张图片
视频 目录中含 .mp4 等视频文件 内嵌播放器预览，点「保存视频」才复制
网页 / 应用 目录中含网页壁纸的工程文件 整目录复制到保存位置下的同名子文件夹

选好来源后，输入框下方会自动显示识别到的类型。如果显示「未知」，说明这个路径不是可识别的壁纸。

3快速上手

  1. 点「选文件」选 .pkg / .tex，或点「选文件夹」选壁纸目录。
  2. 确认「输出设置」里的保存位置（可点「浏览」修改）。
  3. 点「开始解包」，等待右侧出现预览。
  4. 在图片之间挑选，确认后点「保存」。

壁纸目录在哪

一般位于 SteamLibrary\steamapps\workshop\content\431960\<数字ID>。431960 是 Wallpaper Engine 的创意工坊编号。

小技巧：壁纸来源输入框点一下就会全选，直接 Ctrl+V 粘贴新路径即可覆盖，不用先删干净。保存位置输入框同样支持。

4图片壁纸：预览与保存

底部胶片条

  • 解包完成后，预览区底部会出现一排缩略图，默认选中第 1 张。
  • 单击任意缩略图切换大图，选中的那张会自动滚到中间。
  • 缩略图多时可横向滚动；也支持 ← → 或两侧的 ‹ › 按钮翻页。

保存

操作说明
保存按原名保存到保存位置；若同名文件已存在，会询问「覆盖 / 重命名 / 取消」
另存为弹出文件对话框，自选目录和文件名
文件名输入框留空使用解包出的原名；填写则用你指定的名字保存
提示：解出的图片先放在系统临时目录，所以反复切换图片不会在你的保存目录里留下垃圾文件。

5视频壁纸

选中视频壁纸后点「开始解包」，右侧会直接内嵌播放器，此时不会复制任何文件。

  • 播放器支持暂停、拖动进度条、静音切换。
  • 信息区显示文件名、大小、分辨率、时长，以及是否已保存。
  • 确认没问题后点「保存视频」，才会复制到保存位置；重名时自动加 (1)、(2)。
  • 想放到别的位置，用「另存为」。
如果画面黑屏或提示无法播放：少数壁纸使用 HEVC 编码，需要系统安装对应的解码扩展。可以先「保存视频」，再用本地播放器（PotPlayer / VLC 等）打开确认。

6设置

点右上角设置按钮打开，共三项：

项目作用
保存位置「保存」默认写入的目录，主界面也能直接改
仅提取图片开启：只导出贴图；关闭：连场景里的其他文件一起导出
主题深色 / 浅色 / 娇羞（蜜桃粉），点击立即生效并记住

所有设置自动保存，下次启动沿用。

8常见问题

提示「无法识别该壁纸类型」
确认选的是壁纸目录（里面应含 project.json 或 scene.pkg），或直接选 .pkg / .tex 文件。选了上一层或更深的子目录都可能识别不到。
解包成功，但提示 0 张图片
这个壁纸可能只有视频、音频或网页资源。把「仅提取图片」关掉再试一次；视频请直接看右侧播放器。
网页 / 应用壁纸看不到预览
这类壁纸没有可直接预览的静态图，文件已复制到保存位置下的同名子文件夹，到文件夹里查看即可。
保存时报「权限不足」或失败
换一个非系统盘目录（例如 D:\壁纸\），避免直接存到 C:\Program Files 或需要管理员权限的位置。
启动要等 2~5 秒
界面基于 Windows 自带的 WebView2 渲染，首次启动有初始化开销，属正常现象；启动时出现的渐变画面就是加载过渡。
杀毒软件报警
PyInstaller 打包的程序容易被启发式误报，可添加信任或白名单。程序不联网，也不修改系统设置。
临时文件在哪里
%TEMP%\repkg_ui_cache，可随时手动清空；下次解包会自动重建。
配置文件
exe 同目录的 repkg_ui_config.json，记录保存位置、仅提取图片、主题和上次路径。删掉即恢复默认。

9文件结构

文件 / 文件夹必需说明
壁纸解包.exe是主程序，双击启动
_internal\是运行库与界面资源，请勿删除或移动
使用手册.html否本手册，双击用浏览器打开
repkg_ui_config.json否首次运行后自动生成
分发提醒：这是绿色版，拷贝时请把整个文件夹一起复制，只拿 exe 无法运行。建议右键 exe →「发送到」→「桌面快捷方式」。
